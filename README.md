# shehryarshahid.github.io
Personal Portfolio Website

## About
A modern, responsive personal portfolio website built with HTML, CSS, and JavaScript. Features dynamic GitHub project loading and showcases skills and experience.

## Features
- 🎨 Modern dark theme with gradient accents
- 📱 Fully responsive design
- 🚀 Dynamic project loading from GitHub API
- ✨ Smooth animations and transitions
- 🔒 Secure with CDN integrity checks
- 🎯 SEO optimized

## Sections
- **Home**: Hero section with introduction
- **About**: Personal bio and skills
- **Projects**: Automatically displays GitHub repositories
- **Contact**: Links to connect

## GitHub Pages Setup
This website is designed to work with GitHub Pages. To enable:
1. Go to repository Settings
2. Navigate to Pages section
3. Select the branch (main or copilot/add-personal-website)
4. Save and wait for deployment

Your website will be available at: `https://shehryarshahid.github.io`

## Local Development
To test locally:
```bash
python3 -m http.server 8000
```
Then visit `http://localhost:8000`

## Technologies Used
- HTML5

- Font Awesome Icons
